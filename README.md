# Movelo

Modern vehicle tracking and security platform.

## Prototype

The first milestone is a mobile-friendly dashboard using simulated GPS103AB telemetry. It will provide:

- Vehicle dashboard
- Live-map simulation
- Fuel status
- Ignition and door status
- Alerts
- Trip/history views
- Architecture ready for live tracker telemetry

## Roadmap

1. Frontend prototype
2. Simulated telemetry service
3. GPS103AB packet ingestion
4. PostgreSQL/PostGIS telemetry storage
5. Alerts and notifications
6. Secure command service
7. Production mobile app
